## ☁️ Azure Services Used

### Azure PostgreSQL Flexible Server

Used for storing application metadata including:

* User Information
* Profile Details
* File Metadata
* Upload Records
* Application Data

### Azure Blob Storage

Used for storing actual uploaded content including:

* Images
* Documents
* PDFs
* Media Files
* User Uploaded Assets

Benefits:

* High Availability
* Scalability
* Secure Object Storage
* Cost Effective Storage Management
